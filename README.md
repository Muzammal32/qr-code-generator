# QR Code Generator

Free online QR code generator built with Next.js. Supports URL/Text, WiFi, and vCard payloads with PNG/SVG export, logo overlay, scan-from-image, and CSV batch generation.

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production Setup

1. Use [.env.production.example](.env.production.example) as your variable reference.
2. Configure the same variables in Vercel (Production environment).
3. Follow the launch checklist in [DEPLOYMENT.md](DEPLOYMENT.md).

## Build

```bash
npm run build
```
